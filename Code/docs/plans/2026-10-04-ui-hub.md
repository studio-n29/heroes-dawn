# Nouvelle interface, lot 1 (coque et hub) — Plan d'implémentation

> **Pour l'exécutant :** SOUS-SKILL REQUIS : superpowers:subagent-driven-development (recommandé) ou superpowers:executing-plans, tâche par tâche. Étapes à cocher (`- [ ]`).

**Objectif :** remplacer l'écran QG unique par une coque de hub (barre de ressources, barre de navigation, pages), avec QG / Équipe / fiche / Recruter / Salon / Infirmerie / Paramètres ▸ Compte fonctionnels, le reste en WIP, et des feedbacks.

**Architecture :** une scène Hub, une coque en prefab, des pages en prefabs. Un `HubNavigator` (C# pur) tient la page courante et la pile ; une fabrique crée chaque page dans un scope VContainer enfant (`CreateScope`) avec sa vue et son présentateur, et le détruit en la quittant. Les éléments non développés passent par un catalogue WIP unique.

**Technique :** Unity 6.6, C# (`#nullable enable`), VContainer 1.19, MessagePipe, UniTask, NUnit, recettes de prefabs. Tout est dans `Code/Heroes Dawn Unity/Assets/`.

**Spec :** `Code/docs/specs/2026-10-04-ui-hub-design.md` (fait autorité). Cible visuelle : `03_Art_UI_UX/Maquettes/ecrans/M10, M11, M12, M20, M21, M30, M31, M80, M85`.

Abréviations de chemins : `P/` = `Code/Heroes Dawn Unity/Assets/_Project/Presentation/`, `E/` = `…/_Project/Editor/Prefabs/Recipes/`, `A/` = `…/_Project/Application/`, `T/` = `Code/Heroes Dawn Unity/Assets/Tests/`. Racine du dépôt de travail : `D:/HeroesDawn-integration` (branche `feature/ui-hub`).

## Contraintes globales
- Paysage 1920×1080, zones sûres de 88 px sur les côtés ; cibles tactiles **≥ 96 px**, 24 px d'écart ; texte **≥ 20 px** ; Bangers (titres, boutons, chiffres) / Comic Neue (texte de plus de 4 mots) ; couleur jamais seule porteuse de sens.
- Une action principale par page (jaune, ou rouge pour MISSION) ; prix et conséquences écrits sur les boutons.
- Vue : `Show…(…Data)` et événements d'intention seulement, jamais de session ni de cas d'usage ; présentateur C# pur (`PresenterBase`), testé avec des doubles ; les pages ne s'inscrivent pas au `BackButtonRouter` (seule la coque le fait).
- Tous les textes dans `Fr` de `P/Common/Loc.cs`. Chaque test porte `[Description("Vérifie que … — parce que …")]`.
- Aucune interface construite par code à l'exécution (`NoCodeBuiltScreensTests`) : tout passe par des recettes + prefabs.
- Retour : onglet autre que QG → QG ; pièce / fiche / réglages → page précédente ; QG → « Quitter le jeu ? ».
- Feedbacks : jamais bloquants, temps réel (`Tween`), `MotionSettings.Reduced` (par défaut **false** : les feedbacks sont actifs) coupe secousses, flashs et éclats.
- Ne jamais modifier ni commiter `00_GDD/*`, `03_Art_UI_UX/*` (hors lecture), `01_Game_Design/05_Equilibrage.xlsx`, `Code/_deploy/`. Pas de remplacement massif de prefabs : générer avec `-overwrite <chemins>` (l'écrasement global renouvelle tous les identifiants).
- Commandes (Unity fermé sur ce projet) : `W=.superpowers/sdd/i` ; tests `$W/run-tests.sh EditMode|PlayMode [filtre]` ; génération `$W/gen.sh [-overwrite Chemin1,Chemin2]`. TEMP est redirigé sur D: par les scripts (C: est presque plein). Point de départ : **EditMode 245/245, PlayMode 18/18**.
- Après chaque série de tests : synthèse en chat (totaux, ce qu'elle prouve, échecs) ; `latest-*.html` commités avec la tâche ; restaurer les fichiers de réglages que Unity réécrit (`Assets/Settings`, `GraphicsSettings`, `UnityConnectSettings`, `Scenes/*` sans changement voulu).

## Points d'attention (Review Focus)
1. **Navigation rapide** (onglets tapés coup sur coup, même page ouverte deux fois) : jamais deux instances d'une page, la précédente est détruite une seule fois. Tâches 1 et 2.
2. **9h00 passe pendant la fiche d'un héros de la boutique** : l'achat est refusé (`Expired`), toast, retour sur Recruter avec la nouvelle boutique, aucun débit. Tâche 4.
3. **Page détruite pendant un appel asynchrone** (entraînement, soin, recrutement en cours) : aucune exception ni appel à la vue après `Dispose`. Tâches 3, 4, 5.
4. **Retour avec une modale ouverte** (confirmation d'achat, « Quitter le jeu ? ») : la modale se ferme, la page dessous ne bouge pas. Tâches 2, 4, 6.
5. **Escouade** : retirer le dernier membre ou en ajouter un 5e affiche l'erreur et ne change rien. Tâche 3.
