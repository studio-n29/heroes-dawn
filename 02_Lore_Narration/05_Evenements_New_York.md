# Événements narratifs — New York

> ~35 événements : **30 génériques** (tirés au hasard dans les pools des cases Événement) + **5 scénarisés** (un par acte, portent le mini-climax).
> Format : illustration + 3-5 lignes de texte + 2 ou 3 choix. Un choix peut demander une famille (grisé sinon).
> Conséquences : Crédits (Cr), PR, fatigue (F), objet, **mise en avant** (la recrue citée apparaît dans la prochaine pool).

## Règles
- Un même événement ne peut pas réapparaître avant 3 ouvertures de zone.
- Les événements marqués d'un acte n'apparaissent qu'à partir de cet acte.
- Aucun choix n'est « piège » : chaque option a un intérêt (sécurité, ressource, recrue, histoire).
