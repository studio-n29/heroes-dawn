# Prompts d’illustrations : cartes Traque (29 nouvelles)

> Descriptifs pour générer les illustrations des 29 nouvelles cartes de l’archétype Traque (marquer puis achever). Palette de l’archétype : rouge cramoisi, noir, réticule de visée ; accent par famille : Matière ambre, Élémentaire cyan, Physique/Bio rouge, Perception violet.
> Chaque scène est à coller avant le style commun. Enregistrer chaque image sous le nom `<id>.jpg` dans `03_Art_UI_UX/Illustrations/Competences/`.

## Style commun
```
stylized semi-3D animated cinematic still, low-poly faceted shading with visible polygonal facets on figures, clothing and rocks, cel-shaded lighting with soft painterly texture, desaturated dark shadows, dramatic rim light, dynamic camera angle (low angle or tight close-up), shallow depth of field, cinematic 16:9 framing, graphic novel animation quality
```

## Descriptif négatif
```
photorealistic, 3D render, plastic skin, extra fingers, deformed hands, blurry face, asymmetrical eyes, text, watermark, logo, cartoon chibi, pastel colors, bright daylight, cape covering face
```
