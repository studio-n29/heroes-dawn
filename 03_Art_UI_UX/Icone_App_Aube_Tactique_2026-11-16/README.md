# Icône d’application Heroes Dawn - Aube tactique

Création avec l’outil Imagegen intégré, à partir de la planche UI `08-combat.png` comme référence de style. Marine, ivoire, or et lumière rose-violet ; étoile à quatre branches et géométrie chanfreinée. Aucun texte incrusté.

- `heroes-dawn-icon-master.png` : master original de génération.
- `heroes-dawn-icon-1024.png` : grand export carré.
- `heroes-dawn-icon-512.png` : export 512 px, inférieur à 1 Mo.
- `heroes-dawn-icon.ico` : icône Windows multitailles (16, 32, 48 et 256 px).
- Autres PNG : 256, 128, 64, 48, 32 et 16 px.
- `prompt.txt` : prompt exact de génération.

Les exports sont opaques, sans coins extérieurs arrondis précalculés. Pour Unity, importer le PNG 1024 comme icône par défaut dans Player Settings et affecter les tailles adaptées aux plateformes. Le PNG 512 peut servir d’export de fiche store. Ces fichiers n’ont pas remplacé les icônes existantes du projet et ne constituent pas un jeu de couches adaptatives Android séparées.
