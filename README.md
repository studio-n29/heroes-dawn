# Heroes Dawn — Documentation projet

Jeu mobile-first de gestion-RPG dans l'univers **Apex Unit**. Moteur : Unity 6.6. Studio N29.

## Arborescence
| Dossier | Contenu |
|---|---|
| `00_GDD/` | GDD maître (vue d'ensemble, source de vérité) |
| `01_Game_Design/` | Specs détaillées : plateau, combat, méta-humains, économie, équilibrage (xlsx), kits, QG/expéditions, mini-jeux |
| `02_Lore_Narration/` | Univers, villes, campagnes, personnages |
| `03_Art_UI_UX/` | Direction artistique 2D, écrans, flows UI |
| `04_Tech_Unity/` | Architecture Unity, data, outils, backend |
| `05_Production/` | Roadmap, jalons, journal des décisions |
| `Code/` | Dépôt du jeu : projet Unity, outils, plans d'implémentation |
| `06_References/` | Benchmarks, inspirations, captures |

## Conventions
- Markdown partout. Noms de fichiers : `NN_Sujet.md` (ex. `01_Plateau.md`).
- Le GDD résume ; le détail vit dans `01_Game_Design/`. Chaque spec renvoie au GDD et inversement.
- Toute décision validée → une ligne dans `05_Production/Decisions.md`.
- Questions non tranchées → section « Questions ouvertes » du GDD.
