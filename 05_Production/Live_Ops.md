# Live-ops & KPIs

## Rythme
- **Saison de 6 semaines** : pass (piste gratuite + premium) + **1 événement** (mini-plateau à durée limitée, thématique).
- **Nouvelle ville ~tous les 6 mois** (Addressables).
- **Vague 2 des recrues de New York** : dans les premières semaines après le lancement.

## Calendrier type d'une saison
| Semaine | Contenu |
|---|---|
| 1 | Nouveau pass, nouveaux cosmétiques |
| 3-4 | Événement (mini-plateau, 10-14 jours) |
| 6 | Récapitulatif, préparation de la saison suivante |

## KPIs suivis (UGS Analytics)
| KPI | Cible indicative à valider en Early Access |
|---|---|
| Rétention J1 / J7 / J30 | 40 % / 15 % / 6 % |
| Durée de session moyenne | 6-10 min |
| Sessions par jour | 3+ |
| Fin du prologue | > 85 % |
| Fin de l'Acte 1 | > 50 % |
| Conversion payeurs | 2-3 % |
| Achat du pass premium (parmi les payeurs) | > 40 % |

Les cibles sont des ordres de grandeur de départ, à recaler sur les premières données.

## Entonnoirs à instrumenter
Installation → connexion → prologue (étapes 1-5) → 1er recrutement → zone 1 → Acte 1 → 1er achat.
