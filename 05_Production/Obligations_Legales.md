# Obligations légales & stores (checklist)

> À faire valider par un juriste avant la sortie. Liste de travail, pas un avis juridique.
> Les cases restent à cocher au fur et à mesure. Échéance : **M2** pour la propriété intellectuelle et les licences (avant de produire les assets), **M4 (bêta)** pour tout le reste.

## Stores
- [ ] **Steam** : déclarer l'usage de contenu généré par IA dans le questionnaire de publication ; achats in-game via les microtransactions Steamworks.
- [ ] **Google Play** : politiques sur les achats intégrés, la collecte de données (Data safety) et le contenu généré par IA.
- [ ] **App Store** : règles sur les achats intégrés (App Store Review Guidelines), étiquettes de confidentialité, « Sign in with Apple » si d'autres connexions tierces sont proposées.
- [ ] Classification d'âge **IARC / PEGI / ESRB** (violence fantastique ; thèmes du canon évités, voir risque R7).

## Données personnelles
- [ ] **RGPD** : consentement pour l'analytics, politique de confidentialité, droit d'accès/suppression (UGS).
- [ ] **COPPA / mineurs** : écran d'âge ; comportement adapté si moins de 13/16 ans.

## Monétisation
- [ ] Pas de loot box (recrutement au choix) : simplifie la conformité (Belgique, Pays-Bas…).
- [ ] Prix affichés TTC par pays ; conditions de vente ; remboursements selon store.

## Propriété intellectuelle
- [ ] Licences des outils IA et des banques audio (usage commercial).
- [ ] Traçabilité de chaque asset (outil, date, licence).
- [ ] Noms : « SCP » exclu (R8), vérifier « Adam West » (R9), recherche d'antériorité sur « Heroes Dawn » (marque).

## Accessibilité & localisation
- [ ] Options d'accessibilité (voir UX).
- [ ] 5 langues relues par des natifs.
